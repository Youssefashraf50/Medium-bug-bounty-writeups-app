# SecReports 📑

**SecReports** is an application designed to collect writeups published on the **Medium platform**. Each writeup that gets published is automatically sorted into its corresponding category/section based on its topic.

## How It Works

- The app runs and fetches new writeups **automatically**, with no manual input required.
- Collected writeups are automatically categorized and placed into their relevant sections.

## Known Issue

Currently, SecReports only starts collecting writeups **from the moment it is installed on your device** — it does not retroactively collect older writeups that were published before installation. Only new writeups published after installation are collected.

This is a known limitation, and a fix for it is planned in a future update.

## Language

The app currently supports **Arabic only**. English language support has not been added yet.

## Status

Actively maintained — future updates will address the historical writeup collection issue and expand language support.
